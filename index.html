Panduan Deploy di GitHub Pages

  1. Buat repository baru di GitHub (contoh: kana-wear-store) lalu upload file index.html ini.
  2. Aktifkan Settings → Pages → Source: Deploy from a branch (main / root).
  3. Buka GitHub Settings → Developer settings → Fine-grained personal access tokens → buat token khusus Only select repositories (pilih repo toko saja) dengan izin Repository permissions → Contents: Read and write.
  4. Tempel token di form samping, lalu klik Simpan & Tes Koneksi dan Push Katalog ke Repo.

Jaminan Keamanan (Cyber Security):

Token GitHub tidak pernah ditulis ke file repository atau kode publik. Token hanya tersimpan lokal di browser Admin. Pembeli hanya membaca file statis data/catalog.json dan gambar di folder images/products/.

Catatan GitHub Pages: Setelah Admin menambah/menghapus produk, file langsung masuk ke folder repo, dan GitHub Pages biasanya memperbarui tampilan publik dalam 30–60 detik.

Portabilitas Data Serverless (JSON)
